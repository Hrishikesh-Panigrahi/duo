# Gotchas

Things that have cost time before. Add to this when something surprises you.

## Build and CSS

- **Tailwind 4 scans every file that isn't gitignored**, including markdown and scripts. A word like `static`,
  `hidden` or `contents` in a doc becomes a CSS rule. `src/index.css` excludes `docs/`, `scripts/`, `.claude/`
  and `CLAUDE.md` with `@source not`; add a line there for any new non-UI folder.
  To check CSS is unchanged, build from a clean `git archive` export, never from a working tree with scratch files.
- **The service worker (vite-plugin-pwa, autoUpdate) serves the previous bundle** on the first reload after a
  rebuild. Before trusting a result, unregister the service worker and clear Cache Storage (DevTools →
  Application), or use a fresh profile.
- `npm run build` runs `tsc --noEmit` first. TypeScript 7 is the native compiler, so error text can differ from
  older tsc output.
- `dist/_headers` is generated by `vite.config.ts`. Don't hand-edit it, and don't add a `public/_headers`.

## Supabase

- **Ciphertext checks are `NOT VALID`.** They block plaintext on every new insert or update, but old rows can
  still be plaintext. Code must not assume every row has a `cipher`; it must refuse to show one without it once
  the space is encrypted.
- **A `spaces` row from before encryption** fails any update until its plaintext name is cleared. The
  `direct_media` migration handles this in `enable_e2e` and `join_space`.
- **Applying migrations to live** means pasting them into the SQL editor. Wrap the file in `begin; … commit;`, and
  check the editor really holds the file before pressing Run: `/sql/new` can reopen an older snippet over it.
- Free projects pause after a week idle. Resume them from the dashboard.
- Local Supabase needs Docker. Use `docker exec -i` (with `-i`) to pipe SQL from a heredoc into the database
  container.

## Realtime

- supabase-js uses Realtime protocol 2.0.0. **Broadcasts and presence travel as binary frames**, while
  `postgres_changes` are JSON. A text search over a capture misses broadcasts unless you decode the frames.
- `supabase.channel(name)` returns any existing channel with that name, even one still being torn down. That's
  why `SpaceSync` adds a random suffix and `Room` frees its name before reopening.
- `postgres_changes` can't filter DELETEs, so subscriptions are unfiltered and RLS limits them to the space.
- The server rate-limits presence (about 5 updates per 30 s). `PresenceGate` stays at 4.

## UI testing

- Field labels include their hint text, so an exact label match fails. Match by role or position.
- A tab's accessible name includes its unread badge, for example "Chat1".
- A chat bubble's text sits next to the timestamp span, not in a leaf element of its own.
- An email field's built-in validation blocks submitting markup. Use a valid email when testing hostile input in
  other fields.
- The "I have a code" control on space setup is a tab, not a button.
- Random base64 can contain short real words, so a "this word never appears" check on ciphertext needs long or
  unusual markers.
- To corrupt a ciphertext character, change it to a *different* one: replacing `A` with `A` is no change.
- Long-press targets may be off screen. Scroll them into view first.

## Windows and tooling

- Git Bash heredocs can mangle backslashes in regexes and escapes. Write such files with an editor or the Write tool.
- Values in `.env.local` that contain spaces need quotes.
- Remove a directory junction with `cmd //c rmdir <path>` **before** any `rm -rf` of its parent, or the
  junction's target gets deleted too.
- No `gh` CLI on the owner's machine. Push with git and open PRs in the GitHub web UI.
- Public npm and PyPI are blocked on the owner's machine. Installs go through the configured internal registry.
  On a 401 or 403, stop and ask rather than switching registries. The repo's `.npmrc` only keeps registry URLs
  out of `package-lock.json`.
